# nathaliacastelobranco.github.io

Repositório do meu portfólio pessoal, construído com [Astro](https://astro.build).

## Comandos

| Comando           | Ação                                          |
| :----------------- | :--------------------------------------------- |
| `npm install`       | Instala as dependências                        |
| `npm run dev`       | Inicia o servidor local em `localhost:4321`    |
| `npm run build`     | Gera a build de produção em `./dist/`          |
| `npm run preview`   | Faz o preview da build localmente              |
